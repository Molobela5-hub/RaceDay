# Changelog

## [RaceDay Part 3] - Participant enrolment flow improvements

- Added required category selection and improved validation messaging on edit enrolment.
- Added accessibility enhancements for action controls and validation alerts.
- Added client-side duplicate-submit prevention and disabled-button feedback.
- Added server-side validation for category/event consistency during enrolment updates.
- Added enrolment cancellation confirmation to reduce accidental cancellations.
- Improved my enrolments UX with empty-state CTA and editability status badges.
- Improved enrolments ordering by event date and event name.
- Added safeguards when category options cannot be loaded.
- Added server-side event-reference verification before enrolment updates.
